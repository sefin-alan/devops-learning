# VIM

## Key Concepts

- The 'vim' command is a text editor which has several modes, the 3 main modes are: Command, Insert, Visual
- To switch between these modes, use 'esc' and the first letter of the mode (command mode is the default so only 'esc' is needed)
- To save and exit, use [':wq'](02-Commands.md) in command mode

## Basic Navigation

- h j k l: moves left, down, up, right
- gg: jump to top of file
- G: jump to bottom of file

There are many shortcuts and commands in command mode, refer to VIM section in [02-Commands.md](.02-Commands.md)
