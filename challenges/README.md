# Challenges

### Beginner

- [ ] **Deploy a Static Website** – Host a website on S3 with CloudFront
- [ ] **Containerise an App** – Take any app and create a Dockerfile
- [ ] **Automate Backups** – Write a bash script to backup files to S3

### Intermediate

- [ ] **Full CI/CD Pipeline** – Build, test, and deploy a containerised app
- [ ] **Infrastructure with Terraform** – VPC + EC2 + RDS fully automated
- [ ] **Multi-Container App** – Deploy a frontend + backend + database with Docker Compose

### Advanced

- [ ] **Production Kubernetes** – Deploy an app with Ingress, TLS, autoscaling, and monitoring
- [ ] **Multi-Environment IaC** – Terraform with dev/staging/prod using workspaces or Terragrunt
- [ ] **GitOps Pipeline** – ArgoCD or Flux deploying to Kubernetes from Git
